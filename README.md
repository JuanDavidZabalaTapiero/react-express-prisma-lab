# 🚀 Fullstack React + Node.js (Express) Playground

Proyecto de prueba y desarrollo Full Stack diseñado para implementar una arquitectura limpia utilizando **React** en el cliente y un servidor **Node.js (Express)** respaldado por **Prisma 6** y **PostgreSQL**.

---

## 🛠️ Tecnologías

- **Frontend:** React (Vite)
- **Backend:** Express (Node.js)
- **ORM:** Prisma 6
- **Base de Datos:** PostgreSQL
